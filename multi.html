業主大會多人工作台未連接後端

會議協作 · 紙票與電子票

每一票，都有核對依據。

選擇大會投票模式，由工作人員各司其職，統一保存結果及操作紀錄。

A · 現場手機投票

先核實簽到，再發個別投票憑證。

B · 現場＋遠端

另核對遠端出席依據，記錄確認人。

C · 紙票協作

掃碼收票、雙人盲錄、處理差異。

連接會議伺服器

GitHub Pages 只提供畫面。請填已部署的後端網址；未連接時不能同步或錄票。

首次使用及操作次序
  1. 在單機版建立完整名冊及議程，匯出尚未開始的 JSON 備份。
  2. 部署後端並建立管理員；登入後匯入備份，建立新會議。
  3. 核實出席／代理資料，設定投票模式和工作人員帳戶。
  4. 開始會議、開放議程，再發票或發電子投票憑證。
  5. C 模式：收票 → 甲錄入 → 乙盲錄 → 裁定差異 → 核對未收回票 → 截止。

手機鏡頭掃碼需瀏覽器支援 BarcodeDetector；亦可使用 USB QR 掃碼器或輸入票號。OMR 整批讀票尚未啟用。
