# 澳門分層建築物所有人大會｜單機試用版

公開網站：https://ronlam1981.github.io/macau-owners-meeting/

本版本完成第一階段：報告修正、JSON備份還原及第14/2017號法律計票規則校正。
目前仍為單裝置、單分頁原型，沒有後端認證或多人同步，請以測試資料驗收。

## 執行與測試

- 目前入口是 `index.html`，讀取 `meeting-core.js`；兩個檔案需一起部署。
- `app.jsx`、`macau_owners_meeting.tsx` 是未接入網站的舊版本，**不要以它們作正式規則來源**。
- 網站依賴 React、Tailwind 及 Babel CDN，需要網絡；未完成離線化。
- 本機預覽：`python3 -m http.server 8000`，開啟 `http://localhost:8000/`。
- 自動測試：`npm ci`，然後 `npm test`。Node依賴僅供測試，不參與目前部署。
- `tests/core.test.cjs` 測計票、備份驗證、CSV；`tests/ui.test.cjs` 用 React + jsdom 測真實UI處理函數及DOM。

## 本次變更

1. 報告不再引用未定義 handler；以瀏覽器列印儲存 PDF。修正原本只顯示報告而隱藏簽到表／選票的列印 CSS。
2. 結束會議會鎖定資料，關閉已開放議程，未開放議程標示「未表決」。報告補上未投份額、起訖時間、主席及繕立者欄位，標示為草稿。
3. 名冊、出席／代理、議程、票、時間和規則版本可完整匯出 JSON；匯入先驗證及預覽，確認才取代，失敗保留原資料。
4. 同分頁使用 sessionStorage 暫存，重新整理可恢復。關閉分頁前仍須下載 JSON；這不是長期資料庫，也不跨裝置。
5. 修正一般／25%規則為出席加權票數過半加總值下限，新增有條件年度例外及主席選舉；詳見[規則核對](docs/voting-rules.md)。
6. 名冊須完整100%才可開始；支援最多六位小數百分比，轉整數運算。取消把15%當作一律禁止開會的門檻。
7. CSV採完整引號解析，拒絕重複單位、負值、無效份額及未知議程類型，不再默認錯誤類型為一般決議。

## 備份操作

1. 進「管委會及工作人員入口」。
2. 在「資料備份與還原」按「匯出完整 JSON 備份」，確認檔案已下載。
3. 換裝置時進同一網站，按「選擇 JSON 還原」。
4. 核對會議名稱、單位及議程數、狀態。先匯出目的裝置原資料，再按「確認還原並取代目前資料」。
5. 還原進行中會議，可繼續投票；還原已結束會議，在大會控制查看報告。

備份內含姓名、證件資料及前端登入碼，未加密。只存於獲授權的裝置／位置，不要上載公開GitHub。時間及計票規則版本均隨檔保存。不同schema或規則版本直接拒絕，需要另外寫明確遷移程式。

暫存受瀏覽器私隱模式、容量及設定影響；失敗有提示。損壞暫存不會被新測試資料自動覆寫，可選有效備份還原或清空重開。還原會登出原投票者並回到管理頁。

## 驗證範圍與限制

自動測試驗證核心計算、JSON完整往返、無效檔案保留原資料、UI投票及改票／截止、結束報告、列印函數呼叫及恢復。
測試瀏覽器的URL安全政策拒絕本機檔案，因此尚未完成真實瀏覽器列印分頁及手機視覺驗收；jsdom不會模擬排版或PDF輸出。

正式部署前人工驗收：A4報告／簽到表／4張選票分頁、長議程及姓名、Android/iPad下載還原。公開網站尚未因本開發分支自動更新；合併前確認 GitHub Pages 的部署來源。

未完成多人版：管理員尚無真正登入、四位碼仍是展示驗證，同姓名加末碼合併本人單位仍不是可靠人士ID；第30條會後程序、規章特例、複雜業權及子部分大會均未實作。不要直接使用於正式線上投票。
